YOLO26 拥有多个不同级别的规格型号（Scales），此外还针对特定应用场景提供了专门的**结构变体**与**开放扩展版本**。

### 1. 5 个标准尺寸型号（按参数量与精度递增）

YOLO26 的核心标准型号分为 **Nano (n)**、**Small (s)**、**Medium (m)**、**Large (l)** 和 **Extra Large (x)**：

* **yolo26n (Nano)**
* **优势**：参数量最小、推理速度最快、内存占用极低。在 CPU 推理优化上比上一代（YOLO11n）提速达 43%。
* **适用场景**：算力极受限的边缘设备（如嵌入式 CPU、单片机、移动端、低功耗无人机）。


* **yolo26s (Small)**
* **优势**：速度与精度的极佳平衡点。在保持极低延时的同时，相比 `n` 型号显著增强了特征表达能力，大幅提升了对复杂背景和密集小目标的识别准确率。
* **适用场景**：轻量级 GPU 或边缘 AI 盒（如 NVIDIA Jetson Nano / Orin Nano）、嵌入式实时视觉系统。


* **yolo26m (Medium)**
* **优势**：“黄金折中”型号。具备高级别的检测精度（mAP），且在主流显卡上依然能够轻松达到高帧率实时推理。
* **适用场景**：边缘服务器、桌面级 GPU（如 RTX 3060/4060）、工业自动化质检、安防监控。


* **yolo26l (Large)**
* **优势**：高精度模型。在目标严重重叠遮挡、多类别混淆、环境光照剧烈变化等复杂场景下表现强劲。
* **适用场景**：云端服务器或高性能边缘设备（如 Jetson Orin AGX），适合对漏报/误报容忍度极低的工业场景。


* **yolo26x (Extra Large)**
* **优势**：旗舰级精度。拥有系列中最高上限的 mAP 指标，能够捕捉微小的上下文语义特征。
* **适用场景**：云端 API 服务、离线批处理、医疗影像辅助诊断、高精地图标注等对延迟要求不严格但要求极高准确率的领域。

### 2. 针对特定需求扩展的架构变体

在 YAML 结构定义中，YOLO26 还提供了特定分辨率与特征层特化的变体：

* **yolo26-p2 变体**：
* **优势**：增加了 P2 浅层特征检测头，降低了下采样倍率。
* **适用**：专为**极小目标检测**设计（如高空遥感视角下的行人、芯片极微小划痕）。


* **yolo26-p6 变体**：
* **优势**：增加了 P6 深层特征检测头，原生支持更高的输入分辨率（如 1280×1280 或更大）。
* **适用**：超高清全景监控、高分辨率航拍遥感等需要在大图中捕捉细节的场景。



---

### 3. 功能扩展变体：YOLOE-26（开放词汇检测）

* **优势**：扩展为开放词汇（Open-Vocabulary）任务模型。不再局限于训练集固定的类别，可直接通过文本提示（Text Prompt）**或**图像提示（Visual Prompt）动态识别和分割从未见过的自定义新目标。
* **适用**：无需重新训练即可动态扩充识别类的自适应机器人、交互式图像分析系统。

---

### 选型与升级建议

1. **如果当前 yolo26n 出现漏检或精度不足**：优先切换训练 **yolo26s** 或 **yolo26m**。通常增加少量的计算开销就能带来明显的精度（mAP）提升。
2. **如果部署端缺乏 GPU 算力**：坚持使用 **yolo26n**，并开启 YOLO26 原生支持的 `nms=False`（原生端到端推理模式），可极大削减后处理延时。
3. **如果目标在画面中占比极小（仅占几个像素）**：直接选用 **yolo26s-p2.yaml** 或 **yolo26m-p2.yaml** 的架构配置重新训练。
